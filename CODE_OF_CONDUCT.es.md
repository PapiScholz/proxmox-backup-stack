# Código de conducta

[English](CODE_OF_CONDUCT.md) | **Español**

Este proyecto adopta el [Contributor Covenant, versión 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct.html).
El texto que rige es el de [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md), en inglés.
Las traducciones oficiales, incluida la del español, están en
<https://www.contributor-covenant.org/translations>.

En resumen: trato respetuoso, críticas constructivas y nada de acoso, ataques
personales ni publicación de datos privados de otras personas.

Para reportar un comportamiento inaceptable, contactá a
[@PapiScholz](https://github.com/PapiScholz) en GitHub. Todos los reportes se
revisan y la identidad de quien reporta se mantiene en reserva.
